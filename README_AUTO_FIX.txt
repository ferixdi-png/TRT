ОДИН ФАЙЛ ДЛЯ ЗАПУСКА:
  auto_fix_all.bat

ЧТО ДЕЛАЕТ:

ПЕРВЫЙ ЗАПУСК:

1. Установите переменные окружения (один раз):
   
   set RENDER_API_KEY=YOUR_RENDER_API_KEY
   set RENDER_SERVICE_ID=YOUR_RENDER_SERVICE_ID
   set TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN

2. Запустите:
   
   auto_fix_all.bat

ГОТОВО! Скрипт работает автоматически.
