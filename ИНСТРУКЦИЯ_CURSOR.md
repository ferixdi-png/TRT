# 🤖 ИНСТРУКЦИЯ: Автоматическое исправление через Cursor

## 🚀 БЫСТРЫЙ СТАРТ

### Один файл для запуска:

```cmd
cursor_auto_fix.bat
```

**Всё!** Скрипт будет:
- ✅ Мониторить логи на Render каждые 60 секунд
- ✅ Находить ошибки автоматически
- ✅ Создавать задачи для Cursor AI
- ✅ Сохранять промпты в `.cursor/auto_fix_prompt.md`

---

## 📋 КАК ИСПОЛЬЗОВАТЬ

### Шаг 1: Запустите скрипт

```cmd
cursor_auto_fix.bat
```

Скрипт уже настроен с вашими ключами:
- RENDER_API_KEY: YOUR_RENDER_API_KEY
- RENDER_SERVICE_ID: YOUR_RENDER_SERVICE_ID
- TELEGRAM_BOT_TOKEN: YOUR_TELEGRAM_BOT_TOKEN

### Шаг 2: Откройте файл с задачами в Cursor

1. В Cursor откройте файл: `.cursor/auto_fix_prompt.md`
2. Cursor автоматически увидит задачи
3. Нажмите `Ctrl+K` или используйте Chat для исправления

### Шаг 3: Cursor исправит ошибки автоматически

Cursor прочитает задачи из файла и исправит их автоматически.

---

## 📊 ЧТО СОЗДАЁТ СКРИПТ

### 1. Файл с задачами: `.cursor/auto_fix_tasks.json`

Содержит все найденные ошибки в структурированном виде:

```json
[
  {
    "type": "missing_import",
    "error": "ModuleNotFoundError: No module named 'requests'",
    "module": "requests",
    "fix": "Добавить импорт: import requests",
    "priority": "high",
    "status": "pending",
    "created_at": "2025-12-19T11:00:00"
  }
]
```

### 2. Промпт для Cursor: `.cursor/auto_fix_prompt.md`

Форматированный файл с задачами, который Cursor может прочитать:

```markdown
# 🤖 Автоматические задачи для исправления

## 🚨 КРИТИЧЕСКИЕ ОШИБКИ

### Задача 1: telegram_conflict

**Ошибка:**
```
409 Conflict: terminated by other getUpdates request
```

**Исправление:** Удалить webhook и перезапустить сервис
```

## 🔄 АВТОМАТИЧЕСКИЙ РЕЖИМ

### Вариант 1: Cursor читает файл автоматически

1. Запустите `cursor_auto_fix.bat`
2. Скрипт создаст `.cursor/auto_fix_prompt.md`
3. В Cursor откройте Chat (`Ctrl+L`)
4. Напишите: "Прочитай файл .cursor/auto_fix_prompt.md и исправь все ошибки"
5. Cursor исправит всё автоматически

### Вариант 2: Использование Cursor Rules

Создайте файл `.cursorrules` с правилом:

```
## Автоматическое исправление ошибок

При обнаружении файла .cursor/auto_fix_prompt.md:
1. Прочитай все задачи
2. Исправь ошибки автоматически
3. Коммить изменения с сообщением "Auto-fix: исправлено X ошибок"
```

## 🎯 ИНТЕГРАЦИЯ С CURSOR

### Способ 1: Через Chat

1. Откройте Cursor Chat (`Ctrl+L`)
2. Напишите: "Прочитай .cursor/auto_fix_prompt.md и исправь все ошибки"
3. Cursor исправит автоматически

### Способ 2: Через Composer

1. Откройте Cursor Composer (`Ctrl+I`)
2. Выберите файл `.cursor/auto_fix_prompt.md`
3. Нажмите "Fix all issues"
4. Cursor исправит всё

### Способ 3: Автоматически

Добавьте в `.cursorrules`:

```
# Автоматическое исправление
Когда создаётся файл .cursor/auto_fix_prompt.md:
- Прочитай все задачи
- Исправь ошибки автоматически
- Коммить изменения
```

## 📊 СТРУКТУРА ЗАДАЧ

Каждая задача содержит:

- **type**: Тип ошибки (missing_import, telegram_conflict, syntax_error и т.д.)
- **error**: Полный текст ошибки
- **fix**: Описание исправления
- **priority**: Приоритет (critical, high, medium)
- **status**: Статус (pending, fixed, ignored)
- **timestamp**: Время создания
