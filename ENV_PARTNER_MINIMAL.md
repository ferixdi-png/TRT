# 🚀 Partner Quick Start

Запуск партнёрского бота за 5 минут.

## Минимальные переменные окружения

Партнёру достаточно указать **только 4 переменные**:


```env
TELEGRAM_BOT_TOKEN=<ваш токен от @BotFather>
BOT_INSTANCE_ID=partner-your-name
ADMIN_ID=<ваш Telegram user ID>
WEBHOOK_BASE_URL=<URL вашего деплоя>
KIE_API_KEY=<ваш персональный API-ключ для AI>
```


## Общие переменные (от владельца)

Эти переменные **уже настроены владельцем** и используются всеми партнёрами:

```env
DATABASE_URL=<общий Postgres владельца>
STORAGE_MODE=db
```

> Redis настраивается автором автоматически, партнёру ничего делать не нужно.

## Опциональные переменные (партнёр может переопределить)

Если вы хотите использовать свои реквизиты платежей или контакты поддержки, добавьте эти переменные:

```env
# Платёжные реквизиты (если отличаются от владельца)
PAYMENT_BANK=<название банка>
PAYMENT_CARD_HOLDER=<ФИ владельца карты>
PAYMENT_PHONE=<номер телефона для платежей>

# Контакты поддержки (если отличаются от владельца)
SUPPORT_TELEGRAM=<контакт поддержки в Telegram>
SUPPORT_TEXT=<текст информации о поддержке>
```

**Примечание:** Если вы не указали эти переменные, будут использованы значения, установленные владельцем.

## Лишние переменные (удалены из стандартного набора)

Эти переменные **больше не используются** в многотенантной архитектуре:
- `STORAGE_PREFIX` — заменена на `BOT_INSTANCE_ID`
- `GITHUB_COMMITTER_EMAIL`, `GITHUB_COMMITTER_NAME` — только для GitHub storage (устаревшее)
- `GITHUB_BRANCH`, `GITHUB_STORAGE_REPO`, `GITHUB_REPO` — только если вы используете GitHub storage

## Изоляция данных

Все ваши данные автоматически изолируются по `BOT_INSTANCE_ID`.  
Вы **не видите** и **не можете изменить** данные других партнёров.

## Пример для Render

1. Создайте Web Service на Render
2. Подключите ваш fork репозитория
3. Добавьте Environment Variables:
   - `TELEGRAM_BOT_TOKEN`
   - `BOT_INSTANCE_ID` (например `partner-john`)
   - `ADMIN_ID`
   - `WEBHOOK_BASE_URL` (URL вашего сервиса)
4. Deploy!

## Проверка работы

После деплоя отправьте боту команду `/admin` — вы увидите диагностическую информацию:
- BOT_INSTANCE_ID
- STORAGE_MODE
- Database status
- Lock mode
