## Шаг 3: Настройка Environment Variables

### 🔴 Обязательные переменные (без них бот НЕ запустится)

| Переменная | Описание | Пример | Где получить |
|------------|----------|--------|--------------|
| `ADMIN_ID` | **ТВОЙ** Telegram user_id (доступ к /admin) | `6913446846` | https://t.me/userinfobot |
| `BOT_INSTANCE_ID` | Уникальный ID инстанса (**ОБЯЗАТЕЛЬНО уникальный!**) | `partner-ivan-01` | Придумай сам (3-32 символа, a-z, 0-9, ._-) |
| `BOT_MODE` | Режим работы | `webhook` | Всегда ставь `webhook` |
| `DATABASE_URL` | Строка подключения к общей PostgreSQL | *(даёт автор)* | Получи у @ferixdiii |
| `KIE_API_KEY` | **ТВОЙ** ключ KIE AI для генераций | `7da14b33c652ee46...` | https://kie.ai/ (личный кабинет) |
| `TELEGRAM_BOT_TOKEN` | Токен твоего бота | `8564207833:AAEUloa...` | https://t.me/BotFather |
| `WEBHOOK_BASE_URL` | URL твоего сервиса на Render | `https://my-bot.onrender.com` | Появится после создания сервиса |

### 🟡 Настройки оплаты и поддержки

| Переменная | Описание | Пример |
|------------|----------|--------|
| `PAYMENT_BANK` | Название банка для СБП-оплаты | `Альфа Банк` |
| `PAYMENT_CARD_HOLDER` | Имя получателя платежа | `Иван` |
| `PAYMENT_PHONE` | Телефон для СБП-переводов | `89947581999` |
| `SUPPORT_TELEGRAM` | Контакт поддержки (формат @username) | `@ivan_support` |
| `SUPPORT_TEXT` | Текст поддержки в боте | `Пиши, если возникнут вопросы` |

### 🟢 Опциональные (брендинг и расширения)

| Переменная | Описание | Пример | По умолчанию |
|------------|----------|--------|--------------|
| `BOT_NAME` | Название бота в приветствии и меню | `НЕЙРОБОТ` | `FERIXDI AI — Ultra Creative Suite` |
| `BOT_USERNAME` | Username бота без @ (для реф-ссылок) | `my_cool_bot` | Определяется автоматически |
| `WEBAPP_URL` | URL мини-приложения внутри бота | `https://my-bot.onrender.com/webapp` | *(не задан — кнопка не показывается)* |

### 🚫 Переменные которые партнёрам НЕ НУЖНЫ

Эти переменные используются **только на главном инстансе** автора. Если ты их не задашь — всё будет работать корректно:

| Переменная | Зачем | Почему НЕ нужна партнёру |
|------------|-------|--------------------------|
| `REDIS_URL` | Кэш и распределённые блокировки | Опционально, бот работает без Redis |
| `CHAT_ZIMAGE_CHAT` | Автогенерация Z-Image в публичном чате | Фича только для главного бота |
| `CHAT_ZIMAGE_ADMIN_IDS` | Обход кулдауна для админов чата | Связана с CHAT_ZIMAGE_CHAT |
| `CHAT_ZIMAGE_COOLDOWN` | Кулдаун генерации в чате | Связана с CHAT_ZIMAGE_CHAT |

---

### ⚠️ ВАЖНО про WEBHOOK_BASE_URL

Этот параметр появляется **только после создания Web Service**. Порядок действий:
1. Создай сервис **без** `WEBHOOK_BASE_URL`
2. Дождись, пока сервис поднимется и получит публичный URL
3. Скопируй URL сервиса (например `https://trt-1929.onrender.com`)
4. Добавь `WEBHOOK_BASE_URL` = скопированный URL в Environment Variables
5. Нажми **Save** → сервис автоматически перезапустится

### ⚠️ ВАЖНО про WEBAPP_URL

Чтобы внутри бота появилась кнопка **"Открыть приложение"** с мини-приложением:
1. Сначала убедись, что бот работает (прошёл `/start`)
2. Добавь `WEBAPP_URL` = `https://<твой-сервис>.onrender.com/webapp`
3. Сохрани → деплой → внутри бота появится кнопка с мини-приложением

Если `WEBAPP_URL` не задать — кнопка просто не показывается, всё остальное работает.

## Шаг 4: Финальная проверка (2 минуты)

1. Открой **Logs** в Render → убедись, что сервис поднялся без ошибок
2. Проверь в логах: `BOOT_STATUS` и `✅ Application created with all handlers registered`
3. Напиши боту `/start` → должно прийти приветствие с твоим `BOT_NAME` и меню
4. Проверь `/admin` → должна работать (только для `ADMIN_ID`)

## 💰 Оплата

### СБП (Система быстрых платежей)
После перевода пользователь отправляет скрин чека → система автоматически анализирует его и зачисляет баланс.

### Telegram Stars
Всё автоматически — пользователь платит через Telegram, баланс зачисляется мгновенно.

### Ручное начисление (для админа)
Через `/admin` → укажи @username и сумму, например `@ivan 100`

## 🆘 Если бот не работает

1. Скинь логи Render автору
2. Автор по логам скажет, какой ключ/переменная выставлены криво
3. При необходимости автор подключится к твоему Render

Контакт: https://t.me/ferixdiii

### Частые проблемы

| Симптом | Причина | Решение |
|---------|---------|---------|
| Бот молчит на /start | Нет `WEBHOOK_BASE_URL` | Добавь URL и перезапусти |
| `CONFIG VALIDATION FAILED` | Не задана обязательная переменная | Посмотри какая — добавь |
| `BOT_INSTANCE_ID is required` | Не задан `BOT_INSTANCE_ID` | Добавь уникальный ID |
| `KIE_API_KEY missing` | Нет ключа AI | Получи на https://kie.ai/ |
| Health check `ok: false` | БД недоступна | Проверь `DATABASE_URL` |
| Health check `ok: true` + Redis warning | Redis не подключён | **Нормально!** Redis опциональный |

## 🔒 Изоляция данных

Каждый партнёр имеет **полностью изолированные данные**:

- ✅ Свои пользователи
- ✅ Свои балансы
- ✅ Свои платежи
- ✅ Свои генерации
- ✅ Свои рефералы
- ✅ Своя история генераций
- ✅ Свои бесплатные лимиты

Данные изолированы по `BOT_INSTANCE_ID` (= `partner_id`) в PostgreSQL.
**Никто не видит чужие данные!**

## Техническая документация

### Архитектура изоляции

```
PostgreSQL таблица storage_json:
PRIMARY KEY (partner_id, filename)

PostgreSQL таблица referrals:
PRIMARY KEY (partner_id, referred_user_id)
```

### Критические операции (все изолированы по partner_id)

- `get_user_balance` / `add_user_balance` / `subtract_user_balance`
- `charge_balance_once` (с дедупликацией)
- `consume_free_generation_once` (с дедупликацией)
- `add_payment` / `mark_payment_status`
- `set_referrer` / `get_referrer` / `get_referrals`
- `add_generation_job` / `add_generation_to_history`

### Защита от потери данных

- Автоматический бэкап критических файлов
- Блокировка перезаписи данных пустыми
- Блокировка сокращения данных более чем на 80%
- `FOR UPDATE` блокировки для предотвращения race conditions
