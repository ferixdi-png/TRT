# 🚀 Инструкция для партнёров: Запуск бота за 5 минут

## Требования

Партнёр **ОБЯЗАН** предоставить свои собственные ключи. Использование чужих ключей запрещено!

---

## Шаг 1: Регистрация на Render

1. Перейди на https://render.com/
2. Авторизуйся или создай аккаунт

---

## Шаг 2: Создание Web Service

1. Нажми **New → Web Service**
2. Подключись к репозиторию: `https://github.com/ferixdi-png/TRT`
3. Выбери бесплатный тариф

---

## Шаг 3: Настройка Environment Variables

Добавь следующие переменные окружения:

| Переменная | Описание | Пример | Где получить |
|------------|----------|--------|--------------|
| `ADMIN_ID` | **ТВОЙ** Telegram user_id (даёт доступ к /admin) | `6913446846` | https://t.me/userinfobot |
| `BOT_INSTANCE_ID` | Уникальный ID инстанса (ОБЯЗАТЕЛЬНО уникальный!) | `partner-ivan-01` | Придумай сам |
| `BOT_MODE` | Режим работы | `webhook` | Всегда `webhook` |
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgresql://user:***REDACTED***@host/db` | Render PostgreSQL или свой |
| `KIE_API_KEY` | **ТВОЙ** ключ KIE AI | `7da14b33c652ee46...` | https://kie.ai/ (личный кабинет) |
| `PAYMENT_BANK` | Название банка для оплаты | `Альфа Банк` | Твои данные |
| `PAYMENT_CARD_HOLDER` | Имя держателя карты | `Иван` | Твои данные |
| `PAYMENT_PHONE` | Телефон для оплаты | `89947581999` | Твои данные |
| `SUPPORT_TELEGRAM` | Твой контакт для поддержки | `@ivan_support` | Твой username |
| `SUPPORT_TEXT` | Текст поддержки | `Пиши, если вопросы` | Твой текст |
| `TELEGRAM_BOT_TOKEN` | Токен твоего бота | `8564207833:AAEUloa...` | https://t.me/BotFather |
| `WEBHOOK_BASE_URL` | URL твоего сервиса на Render | `https://my-bot.onrender.com` | Появится после создания сервиса |
| `BOT_USERNAME` | **Username твоего бота (БЕЗ @)** - нужен для партнёрских ссылок! | `my_cool_bot` | Из BotFather (то что после @) |
| `BOT_NAME` | Название бота в приветствии (опционально) | `НЕЙРОБОТ` | Придумай своё название |

### ⚠️ ВАЖНО про WEBHOOK_BASE_URL

Этот параметр появляется **только после создания Web Service**. Порядок действий:
1. Создай сервис **без** WEBHOOK_BASE_URL
2. Дождись, пока сервис поднимется и получит публичный URL
3. Скопируй URL сервиса
4. Добавь `WEBHOOK_BASE_URL` в Environment Variables
5. Перезапусти деплой

---

## Шаг 4: Проверка (2 минуты)

1. Открой **Logs** в Render → убедись, что сервис поднялся без ошибок
2. Напиши боту `/start` → должно прийти меню
3. Проверь команду `/admin` → должна работать для владельца

## 🔒 Изоляция данных

Каждый партнёр имеет **полностью изолированные данные**:

- ✅ Свои пользователи
- ✅ Свои балансы
- ✅ Свои платежи
- ✅ Свои генерации
- ✅ Свои рефералы

Данные изолированы по `BOT_INSTANCE_ID` в PostgreSQL. **Никто не видит чужие данные!**

## Техническая документация

### Архитектура изоляции

```
PostgreSQL таблица storage_json:
PRIMARY KEY (partner_id, filename)

PostgreSQL таблица referrals:
PRIMARY KEY (partner_id, referred_user_id)
```

### Критические операции (все изолированы по partner_id)

- `get_user_balance` / `add_user_balance` / `subtract_user_balance`
- `charge_balance_once` (с дедупликацией)
- `consume_free_generation_once` (с дедупликацией)
- `add_payment` / `mark_payment_status`
- `set_referrer` / `get_referrer` / `get_referrals`
- `add_generation_job` / `add_generation_to_history`

### Защита от потери данных

- Автоматический бэкап критических файлов
- Блокировка перезаписи данных пустыми
- Блокировка сокращения данных более чем на 80%
- `FOR UPDATE` блокировки для предотвращения race conditions
