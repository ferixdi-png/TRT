========================
ФАКТЫ
========================
- Telegram 409 Conflict = 2 polling-инстанса или webhook.
- Render может запускать несколько инстансов.
- Единственный рабочий фикс — PostgreSQL advisory lock с живым соединением.
- KIE AI API:
  POST https://api.kie.ai/api/v1/jobs/createTask
  GET  https://api.kie.ai/api/v1/jobs/recordInfo?taskId=...
- Все модели KIE имеют:
  - model (string)
  - model_type (тип модели)
  - input schema (набор параметров)

========================
ЗАДАЧА №1 — TELEGRAM 409 (ОБЯЗАТЕЛЬНО)
========================
1) Перед polling:
   await bot.delete_webhook(drop_pending_updates=True)

2) Реализуй PostgreSQL advisory lock:
   - lock_key зависит от TELEGRAM_BOT_TOKEN
   - SELECT pg_try_advisory_lock
   - если lock не получен → log + exit(0)
   - соединение держать ВЕСЬ runtime
   - release только на shutdown

Без этого проект считается НЕРАБОЧИМ.
